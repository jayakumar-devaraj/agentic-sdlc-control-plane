# pydantic is pinned by agentic-events==0.1.0 (exact ==2.10.4); it is not a free
# choice here. Bumping it requires re-releasing the shared contract package first.
#
# *** agentic-events INSTALLS WHETHER agentic-sdlc-eventbus IS PUBLIC OR PRIVATE. ***
#
# Public  -> anonymous HTTPS, no credential anywhere.
# Private -> EVENTBUS_READ_PAT, a fine-grained read-only PAT scoped to that repository,
#            set as a repository secret. Optional: nothing fails when it is absent and
#            the repo is public (ADR-0015).
#
# That is a deliberate reversal of commit 080ffae, which removed the build-time PAT on
# the premise that eventbus "is public". The premise did not hold - visibility gets
# toggled - and a build whose success depends on a setting nobody remembers is not a
# build. 080ffae's actual *security* concern is preserved rather than overruled: the
# image handles a real PAT at runtime, so the build credential is a BuildKit secret that
# never becomes a layer, and `Assert the built image carries no credential` still checks
# /root/.gitconfig is 0 bytes.
#
# The old `jayakumard10` owner below is a rename redirect and resolves correctly. It is
# deliberately not rewritten: it looks like the cause of an auth failure and is not, and
# changing it during a red build would confuse the two.
